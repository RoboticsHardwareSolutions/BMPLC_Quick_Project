# Modbus RTU Project Context (uv workflow)

## Команды управления окружением
- Синхронизация зависимостей: `uv sync`
- Запуск главного скрипта: `uv run main.py`
- Добавление новых пакетов: `uv add <package_name>`

## Правила кодогенерации
- Всегда используй синтаксис `pymodbus` версии 3.x.
- Для RTU используй исключительно класс `ModbusSerialClient`.
- Параметр ID устройства передавай как `slave=...` внутрь методов чтения/записи.
- Обязательно добавляй блок `try...finally` для гарантированного закрытия `client.close()`.
